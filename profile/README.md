학교별 기출문제를 분석해 **출제 패턴에 맞는 내신 영어 서답형 시험지**를 AI로 만들어 주는 학원용 서비스입니다.

## ✨ 주요 기능

- **기출 분석** — 학교 기출 PDF를 올리면 문항 단위로 추출하고, 유형별 출제 패턴을 집계합니다.
- **출제 프로필** — 분석 결과를 강사가 확인하고 직접 다듬어 확정합니다.
- **AI 문제 생성** — 교과서 지문 단위로 출제 프로필에 맞는 서답형 문제를 생성하고, 규칙 기반 검증과 AI 풀이 검증을 거칩니다.
- **시험지 출력** — 학원 로고가 들어간 문제지·정답지를 PDF로 내려받습니다.
- **학원 협업** — 원장이 학원을 만들고 초대 코드로 강사를 추가해, 학교·학년별 워크스페이스를 함께 씁니다.
